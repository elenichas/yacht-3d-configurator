# Yacht Concept Studio

A proof-of-concept 3D yacht configurator for guided ideation and presentation. It starts with an original procedural placeholder yacht and exposes progressive controls for proportions, architecture, materials, environment, and camera views.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js. The default is `http://localhost:3000`.

## Verify

```bash
npm run lint
npm run build
```

## Current scope

- Real-time React Three Fiber scene
- Procedural hull and modular superstructure placeholder
- Guided and advanced configuration modes
- Length, beam, bow, superstructure, upper-deck, and glazing controls
- Hull and deck material options
- Studio, daylight, and dusk environments
- Perspective, profile, top, and front camera views
- Presentation and reset modes
- Responsive layout, keyboard focus states, and reduced-motion support

The output is explicitly conceptual and is not naval engineering or construction documentation.
